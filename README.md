# WEB430 - DevOps

Bellevue University

Student: Jonathan Cantu
Professor: Richard Krasso

This course introduces students to modern DevOps practices with an emphasis on automation, collaboration, and AI-augmented development workflows. Students explore foundational DevOps concepts, including continuous integration, automated testing, deployment pipelines, monitoring, and security, while also examining how emerging AI tools and intelligent agents are reshaping software delivery. Through a combination of reading, hands-on activities, and guided analysis, students gain practical experience with DevOps processes and learn how AI-enhanced approaches improve software quality, reliability, and team efficiency.
